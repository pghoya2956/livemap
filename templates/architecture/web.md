# 웹 화면

사용자가 브라우저에서 보는 화면 전부. 한 문장으로 이 부품의 책임을 적는다.

- id: web
- 폴더: web/src

## 층: 화면

라우트 하나에 대응하는 페이지. 층마다 사람이 읽는 문장 하나와 엔진이 재는 한 줄(`가져올 수 있는 층`)을 나란히 둔다.

- id: pages
- 폴더: web/src/pages
- 가져올 수 있는 층: lib

## 층: 자료 받기

서버 호출과 형 변환. 화면을 가져오지 않는다. `—`는 어느 층도 가져올 수 없다는 뜻이다.

- id: lib
- 폴더: web/src/lib
- 가져올 수 있는 층: —

## 흐름: 첫 기능

사용자가 무엇을 하면 무엇이 일어나는지 한 문장. `단계`는 여정 정본의 `<여정 id>/<장면 id>`, `지나는 곳`은 종류 낱말(화면·파일·함수·API·DB 함수·테이블) 뒤 좌표를 → 로 잇는다.

- id: first-flow
- 단계: j1/s1
- 지나는 곳: 화면 / → 함수 web/src/pages/Home.tsx:Home → API GET /api/items → DB 함수 list_items → 테이블 app.items
